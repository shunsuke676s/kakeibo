# 家計簿（PWA）

iPhoneのホーム画面から使う、自分専用の家計簿です。データはiPhoneの中だけに保存され、サーバーには送られません。

## できること
- ホーム：今月の収支、4つのメニュー（支出入力／収入入力／グラフ表示／管理画面）、最近の記録
- 支出入力：日付（今日が初期値）・大分類・小分類・金額・備考。続けて何件でも入力できます
- 収入入力：収入日・金額・備考
- グラフ：支出／収入／貯金額のタブ、日別・週別・月別・年別の切り替え、大分類・小分類の色分け内訳、収支のプラスマイナス表示
- 管理画面：大分類・小分類の追加・名前変更・並べ替え・削除、既定値の設定、CSVバックアップ
- 記録をタップすると編集・削除できます。オフライン動作、ダークモード対応

## 公開手順（GitHub Pages・無料・Windowsだけで可能）
1. GitHubでアカウントを作り、新しいリポジトリ（例：`kakeibo`）を作成
2. リポジトリ画面の「Add file → Upload files」で、このフォルダの中身（`icons`フォルダごと）をアップロードしてCommit
3. 「Settings → Pages」で Source を `Deploy from a branch`、Branch を `main` / `(root)` にして保存
4. 数分後に `https://ユーザー名.github.io/kakeibo/` で開けるようになります

※無料プランのGitHub Pagesはリポジトリを公開(Public)にする必要がありますが、公開されるのはプログラムだけで、家計簿のデータは含まれません。検索エンジンに載らない設定（noindex）も入れてあります。コードも非公開にしたい場合は、Cloudflare PagesやNetlifyなら非公開リポジトリから無料で公開できます。

## iPhoneへの追加
1. SafariでURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. **以後は必ずホーム画面のアイコンから起動**してください。iPhoneではSafariで開いたときとホーム画面アプリのときでデータの保存場所が別になります。

## バックアップ
設定タブの「CSVで書き出す」から「ファイルに保存」でiCloud Driveなどに保存できます。CSVはWindowsのExcelでもそのまま開けます。機種変更時は新しいiPhoneで「CSVを読み込む」を使ってください。

## 更新するとき
ファイルを書き換えてアップロードしたら、`sw.js` 3行目の `kakeibo-v1` を `kakeibo-v2` のように変えてください。アプリを2回起動し直すと新しい版になります。
